# Wix HTML 요소 높이 (3차, C2 디자인)

Wix HTML 요소는 내용에 맞춰 높이가 바뀌지 않는다. 페이지 길이가 바뀌면 이 표를 다시 재고, Wix 에디터에서 요소 높이만 고친다.

재는 법(저장소 루트): `node tools/verify/heights.js site/<페이지>.html --md`

- 데스크톱 = 폭 980, 1100, 1280, 1440, 1920 가운데 가장 큰 문서 높이, 모바일 = 폭 320. 둘 다 +24px 뒤 10 단위로 올림.
- 3차 키트(tools/kit.py)는 한 페이지의 KO 높이와 EN 높이를 같게 맞춘다(구간마다 두 언어 가운데 큰 쪽을 예약). 그래서 언어별 값이 같고, Wix의 `postMessage({lang})` 로 언어가 바뀌어도 아무것도 움직이지 않는다.
- 목록(논문·학회 발표·특허)과 갤러리는 가장 긴 쪽(필터·쪽 전체, 두 언어)의 높이를 예약하므로, 쪽을 넘기거나 필터를 바꿔도 높이가 그대로다. 데이터가 늘면 다시 잰다.
- 데스크톱 높이는 폭에 따라 달라진다(사진과 첫 화면이 폭에 비례). 요소가 980px 고정 폭이면 980 값만으로 충분하다. 아래 "980" 칸을 참고.
