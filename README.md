# WIX_DEV

청각재활연구소(RIHE) 홈페이지 [www.smilesnail.org](https://www.smilesnail.org)의 HTML 임베드 코드 저장소입니다.

사이트 본문은 대부분 Wix의 **HTML iframe 요소**에 넣은 코드로 되어 있습니다. Wix 에디터 안의 코드는 이력이 남지 않고, 누가 무엇을 바꿨는지 알 수 없어서 원본을 여기에 둡니다.

## 구조

```
embeds/<페이지>/<요소 ID>.<이름>.html   Wix 요소 하나 = 파일 하나
docs/site-map.md                          페이지별 요소 ID, 에디터 높이, 파일 위치
tools/fetch_live.py                       게시된 사이트에서 모든 임베드를 다시 받아오는 스크립트
```

요소 ID는 Wix 에디터에서 요소를 클릭했을 때 오른쪽 아래 코드 패널에 보이는 ID(`#html1`, `#mobileHtml1` 등)와 같습니다.

**모든 페이지에 데스크톱용(`html1` 등)과 모바일용(`mobileHtml1`) 임베드가 따로 있습니다.** 내용을 고칠 때는 두 파일을 모두 고쳐야 모바일에도 반영됩니다.

## 수정해서 사이트에 반영하는 순서

1. 이 저장소에서 `embeds/` 아래 파일을 고치고 커밋합니다.
2. Wix 에디터에서 해당 페이지의 요소를 클릭하고 **코드 입력** 칸의 내용을 파일 내용으로 통째로 바꾼 뒤 **업데이트**를 누릅니다.
3. 내용 길이가 바뀌었으면 요소 높이를 맞춥니다(iframe은 높이가 자동으로 늘어나지 않습니다).
4. 에디터 오른쪽 위 **게시하기**를 눌러야 실제 사이트에 반영됩니다.

## 에디터에서 직접 고친 경우

Wix 에디터에서 코드를 바로 고치고 게시했다면, 아래 명령으로 게시된 코드를 다시 받아오세요. `git diff`로 무엇이 바뀌었는지 확인한 뒤 커밋하면 저장소와 사이트가 다시 일치합니다.

```
python3 tools/fetch_live.py
```
