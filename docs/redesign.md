# 사이트 개편 시안 (2차, "달팽이관")

새 디자인은 `site/` 폴더에 있습니다. 아직 실제 사이트에 적용하지 않은 시안입니다. 1단계 수정(`embeds/`, [paste-list.md](paste-list.md))과는 별개라서, 1단계는 지금 바로 적용해도 됩니다.

## 디자인 방향

- **담백하게.** 흰 바탕에 남색(#1b3d6f) 하나를 씁니다. 연구실 색(Basic 초록, Hearing 회청, HeAD 파랑, Audiso 황토)은 글자에 쓰지 않습니다. 작은 표시선과 밑줄에만 씁니다. 그림자, 그라데이션, 아이콘 장식은 없습니다.
- **연구소를 보여 주는 한 가지 모양: 달팽이관.** smilesnail의 snail이 달팽이관입니다.
  - 홈 첫 화면에서는 가는 선 하나가 달팽이관 모양으로 감깁니다. 선 위의 눈금은 실제 달팽이관의 주파수 배열(입구 20 kHz에서 꼭대기 20 Hz)을 따릅니다.
  - 다른 페이지에서는 제목 아래 가로선이 끝에서 작은 나선으로 말립니다.
- **움직임은 조용하게, 한 번씩만.**
  - 달팽이관은 처음에 한 번 그려집니다. 그 뒤에는 소리가 지나가듯 맥박 하나가 천천히 흐릅니다. 사이트 전체에서 계속 움직이는 것은 이것 하나뿐이고, 화면 밖에 있으면 멈춥니다.
  - 각 구역은 스크롤로 화면에 들어올 때 살짝 나타납니다.
  - 논문·특허 수는 눈금 막대로 보여 줍니다. 항목 하나가 눈금 하나입니다.
  - 기기에서 '동작 줄이기'를 켠 사람에게는 처음부터 모든 것이 정지 상태로 보입니다.
- **글꼴.**
  - 제목: Hahmlet.
  - 본문: Noto Sans KR.
  - 연도와 숫자: DM Mono.
  - 페이지마다 필요한 글자만 받아 와서 가볍습니다.
- **갤러리 페이지 신설(/gallery).**
  - 사진을 연도별로 나눠 봅니다. 사진을 누르면 그 자리에서 크게 열리고, 키보드 화살표로 넘길 수 있습니다.
  - 아래에는 영상 3개가 이어집니다.
  - 홈과 About 맨 아래에는 사진 5장 미리보기가 들어가고, 누르면 /gallery로 갑니다. 지금 About 아래에 있는 작은 Pro Gallery를 대신합니다.

## 영상과 사진은 어디에 있나

### 영상: `data/videos.json`

영상은 홈과 /gallery에 나옵니다. 누를 때만 재생되고(소리·조작 버튼 포함), 자동 재생은 하지 않습니다.

```json
{
  "title_ko": "연구소 소개 영상",
  "title_en": "Institute introduction",
  "duration": "2:29",
  "date": "",
  "src": "https://video.wixstatic.com/video/.../480p/mp4/file.mp4",
  "poster": "https://static.wixstatic.com/media/...f001.jpg",
  "thumb": "https://static.wixstatic.com/media/...f003.jpg"
}
```

- **영상 빼기:** 해당 항목 `{ ... }`을 지웁니다. 쉼표도 맞춰 지웁니다.
- **영상 넣기:**
  1. Wix 미디어 관리자에 영상을 올립니다.
  2. 영상의 '··· > URL 복사'로 mp4 주소를 받아 `src`에 넣습니다. 해상도(480p/720p)는 Wix가 만든 것만 있으므로, 복사한 주소를 그대로 씁니다.
  3. `poster`(재생 전 큰 그림)와 `thumb`(목록 작은 그림)에는 이미지 주소를 넣습니다. 따로 만든 이미지를 Wix에 올려 그 주소를 넣으면 가장 좋습니다.
- **순서:** 파일에 적힌 순서대로 나옵니다. 첫 번째 영상이 처음 화면에 걸립니다.
- 영상을 모두 지우면 영상 구역이 사라집니다.

### 사진: 두 가지 방법

**방법 1. `data/gallery.json` (지금 방식).** 홈·About 미리보기와 /gallery가 이 목록을 씁니다.

```json
{
  "media": "b8629b_9d88869d4ddd410ca48f2baf99bf7f25~mv2.jpg",
  "file": "IMG_0168.JPG",
  "width": 960, "height": 640,
  "caption_ko": "청각재활연구소 구성원",
  "caption_en": "Members of RIHE",
  "year": "2021"
}
```

- `media`는 Wix 미디어 주소 `https://static.wixstatic.com/media/<여기>`의 마지막 부분입니다.
- `width`와 `height`는 원본 크기입니다.
- 홈·About 미리보기에는 앞의 5장이 나옵니다. 앞에 둘 사진을 위로 올리세요.
- 고친 뒤에는 다시 만들어(아래 '고치고 다시 만드는 법') 붙여넣어야 합니다.

**방법 2. Wix CMS 컬렉션 (추천, /gallery 페이지용).**

- 대시보드 > CMS > Gallery에서 사진을 올리고 캡션과 연도만 적으면 /gallery에 바로 나옵니다.
- 코드를 다시 붙이거나 게시할 필요가 없습니다.
- 처음 한 번만 컬렉션을 만들고 페이지 코드를 붙이면 됩니다. 방법은 [tools/pages/gallery.md](../tools/pages/gallery.md)에 있습니다.
- 컬렉션을 읽지 못하면 HTML 안의 기본 사진이 그대로 보입니다. 페이지가 비는 일은 없습니다.
- 홈·About 미리보기 5장은 계속 `data/gallery.json`을 씁니다.

### 구성원 사진과 데이터: `data/people.json`, `data/publications.json` 등

구성원 사진은 `people.json`의 `photo`에 들어 있습니다. 사진이 없는 사람은 성 한 글자로 표시됩니다. 논문(120), 학회 발표(94), 특허(80)는 각각의 json에 있습니다. 논문을 추가하면 Research, 해당 연구실, 홈의 숫자가 함께 바뀝니다. 저자 목록은 게시된 원문 그대로입니다. 바꾸지 않았습니다([author-review.md](author-review.md)는 검토용 자료일 뿐입니다).

## 고치고 다시 만드는 법

1. `data/*.json`을 고칩니다. 문구를 고치려면 `tools/pages/<페이지>.py`나 공통 문구가 있는 `tools/kit.py`를 고칩니다.
2. `python3 tools/build.py`를 실행하면 `site/*.html`이 다시 만들어집니다.
   - `--preview`를 붙이면 오른쪽 아래에 KO/EN 버튼이 있는 미리보기가 `site-preview/`에 만들어집니다.
   - `--only home,gallery`처럼 페이지를 고를 수 있습니다.
3. 바뀐 파일을 Wix 요소에 붙여넣고 게시합니다.

개발용 설명(디자인 규칙, 부품 목록, 높이 측정 방법)은 [tools/KIT.md](../tools/KIT.md)에 있습니다.

## Wix에 적용하는 순서

1. **/gallery 페이지 만들기.**
   1. 에디터 > 페이지 추가 > 빈 페이지를 만들고, 주소를 `gallery`로 둡니다.
   2. 'HTML iframe' 요소를 하나 넣고 `site/gallery.html`을 붙입니다.
   3. 메뉴에 '갤러리'를 추가합니다.
2. **페이지마다 데스크톱 HTML 요소 하나**(`#html1`)에 `site/<페이지>.html`을 붙이고 아래 표대로 높이를 맞춥니다.
   - 홈과 About처럼 요소가 여러 개인 페이지는 나머지 HTML 요소와 Wix 기본 요소(영상, 인포그래픽, Pro Gallery 등)를 지웁니다.
   - 내용은 새 파일에 모두 들어 있습니다.
3. **모바일 에디터**에서 모바일 요소(`#mobileHtml1`)에 같은 파일을 붙이고 모바일 높이를 맞춥니다.
4. **한 페이지씩 확인**하고 게시합니다. 지도, 영상 재생, 같은 페이지 안 '바로가기' 버튼, 갤러리 CMS를 실제 사이트에서 확인하세요.

## 영어 페이지 설정

모든 파일에 한국어와 영어가 함께 들어 있습니다. 어느 언어를 보여 줄지는 Wix 페이지가 알려 줍니다.

1. 대시보드에서 **Wix Multilingual**을 추가하고 영어를 두 번째 언어로 켭니다. 영어 페이지 주소는 `/en/...`을 가정했습니다.
   - 켜기 전에는 영어 화면의 링크가 404가 됩니다.
   - 영어판을 늦게 켤 거라면 `tools/kit.py`의 `EN_PREFIX = '/en'`을 `''`로 바꾸고 다시 만드세요.
2. 각 페이지의 페이지 코드(에디터 아래 코드 패널)에 다음을 넣습니다.

```js
import wixWindowFrontend from 'wix-window-frontend';

$w.onReady(function () {
  const lang = wixWindowFrontend.multilingual.currentLanguage; // 'ko' 또는 'en'
  ['#html1', '#mobileHtml1'].forEach((id) => {
    try { $w(id).postMessage({ lang }); } catch (e) {}
  });
});
```

   - /gallery 페이지는 [gallery.md](../tools/pages/gallery.md)의 코드 맨 아래 주석을 쓰면 됩니다.
3. 메뉴, 헤더, SEO 제목 같은 Wix 기본 요소는 Multilingual 번역 관리자에서 영어로 입력합니다.

## 확인·준비가 필요한 것

**사진·자료**
- 사진이 없는 구성원 7명의 사진. 이동혁, 손명석, 고재욱은 더 좋은 사진이 있으면 바꿔 주세요.
- 갤러리에 넣을 사진. 각 사진에 한국어·영어 캡션과 연도가 필요합니다. 지금은 실제 사진 6장뿐입니다.
- 영상 대표 이미지(포스터). 지금은 Wix가 자동으로 뽑은 장면입니다. 특히 소개 영상은 흰 화면이라 따로 만든 이미지가 좋습니다.
- 로고 파일:
  - 그림자 없는 HeAD Lab 로고.
  - 진한 색 ILIAS 로고.
  - 데이터센터 로고 벡터(SVG) 파일.
- 기초 연구 개요도 중 흰 바탕 버전.

**문구 승인**
- 홈 연구 분야의 한국어 제목(기초 연구 / 빅데이터·인공지능 / 의료기기 / 임상시험).
- 홈 첫 화면 옆 문구("smilesnail의 ‘snail’, 달팽이관..."와 영어).
- 갤러리 소개 문구.
- 홈의 줄인 영문 연구소장 약력.
- 새 제목들: '구성원'(People), '연구실 소개', '미션 · 비전'.
- HeAD Lab 연구 주제를 한국어 화면에서 한국어 제목으로 보일지.
- 영어 문구 전체(초안). 특히 교수님 직함과 학과명의 공식 영문 표기.
- 구성원 영문 이름. 이은수 님과 졸업생 등 확인되지 않은 분은 영어 화면에서도 한글로 나옵니다.

**Wix 설정**
- 사이트 정보의 주소를 '의학관 318호'로 고칩니다(지금 '4층 기능연구실'로 되어 있음).

- Research 그림을 누르면 원본 이미지가 새 탭으로 열립니다. 이대로 둘지 정해 주세요.
